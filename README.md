# PKD Compass Desktop Downloads

Standalone Mac and Windows installers for the local PKD Compass health journal.
No health records are hosted in this repository. The desktop app stores an
encrypted vault on your computer and does not need a website connection.

Website: https://pkdcompass.netlify.app/download

## Preview status

The first release is a testing preview, not a signed public release. Mac
Developer ID signing/notarization and Windows publisher signing are pending.
Your operating system may block it. Do not disable security protections;
wait for a signed release for regular use. Use fictional data for testing.

Choose a release under **Releases**, read its notes and check the included
SHA-256 checksums. Mac downloads distinguish Apple silicon and Intel. Windows
downloads are x64 setup executables. No native iPhone/iPad installer is offered.

Keep your vault passphrase and encrypted backups safe. They cannot be recovered
by us. Updates are manual; make a backup and quit before updating. Health
records never sync automatically. Exported CSV reports/documents are not encrypted.

The local edition includes manual labs, symptoms, BP logs, food/nutrients,
medication dose logging, documents and care planning. Cloud services, AI,
barcode lookup and scheduled background reminders are not included.

For personal organization, not medical advice, diagnosis or treatment.
