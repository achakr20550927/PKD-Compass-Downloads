# PKD Compass 1.0.0-preview.2

Testing preview only. **Mac Developer ID signing/notarization and Windows
publisher signing are still pending.** This release does not resolve Apple's
"could not verify" warning. Do not disable security protections to run it.
Use fictional test data; wait for a signed release for regular use.

## Changes

- Website-matched Inter typography and blue/teal vault entry screen.
- Fonts bundled locally and cached by the separate web edition for offline use.
- Native multi-resolution Mac icon generated by Apple iconutil.
- Explicit disk image icon and distinct "PKD Compass Installer" volume name.
- No changes to storage format, vault identity or journal workflows.

Choose arm64 DMG for Apple silicon, x64 DMG for Intel Mac (macOS 13+), or
x64 EXE for Windows. Back up and quit the app before replacing an installation.
Existing preview 1 data stays in the same application-data directory.

Storage unit tests, desktop vault restart/export/restore and responsive browser
workflows passed. Physical Intel Mac and consumer Windows testing remains
pending. One automated WebKit offline test remains skipped; no native iOS
installer is included. Check SHA256SUMS.txt for file integrity.

No health-data hosting or automatic sync. Core manual journal functions are
included; cloud services, AI, barcode lookup and background reminders are not.
